A program that writes one sharp, funny loading-screen tip (max 200 characters) for stressed developers and AI coding agents to `/output/entry.txt`.

The tip reframes the wait: the loading bar isn't stuck, it's reading your code and quietly judging your variable names — a nudge to breathe while the build finishes. Stdlib only, no dependencies.

## Run

```sh
npx tsc main.ts --module nodenext --target es2022 --outDir dist
MAKEFUN_OUTPUT_DIR=/tmp/out node dist/main.js
```

## Entry

One line, plain text, 200 characters or fewer.
